Telugu → English live subtitles (bookmark, version 2)

This runs inside YouTube itself, so it can read the auto-generated Telugu captions and show English over the video. No extension needed.

Step 1: copy the code

Step 2 (Android Chrome): save it as a bookmark

  1. Tap ⋮ → ☆ to bookmark this page.
  2. Tap ⋮ → Bookmarks, tap ⋮ next to the bookmark you just made, then Edit.
  3. Change the name to tren. Delete the address and paste the code in its place. Save.

Step 3: use it

  1. In Chrome (not the YouTube app) open your movie at youtube.com or m.youtube.com.
  2. Tap the address bar, type tren, and tap the suggestion with the star ☆ icon.
  3. English subtitles appear over the video. Use YouTube’s own fullscreen button. Run it again to switch it off.

On a PC

Drag this button to your bookmarks bar, open the movie on YouTube, then click it: tren

If you see “Translation blocked: …” over the video, YouTube refused the translation request. Send me that exact text.
